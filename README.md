# Mechanistic Causal Reasoning in LLMs: Diagnostic Insights from  Implicit Causal Chain Inference in Climate Discourse

## Introduction

This folder contains the Data and Code for reproducing the causal chain inference experiments and the diagnostic evaluation performed in Allein, L., Pineda-Castañeda, N., Rocci, A., Moens, M.-F. (2025): *Mechanistic Causal Reasoning in LLMs: Diagnostic Insights from  Implicit Causal Chain Inference in Climate Discourse*.

## Causal Chain Data

The datasets containing the generated causal chains for PolarIs3CAUS and PolarIs4CAUS can be found as JSON Lines (.jsonl) in the Chains folder. The dataset schema is given in detail [below](#dataset-format)

The dataset is licensed under the [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) license.

### Causal Chains

JSON Lines files with the original PolarIs3CAUS and PolarIs4CAUS data combined with the causal chains generated by each models are included in the folder Chains --> Polaris3_chains and Polaris4_chains. The file name mentions the model that performed the generation, e.g. ```Polaris4_full_with_chains_o1.jsonl``` contains chains generated by o1.

The causal chain data for PolarIs3CAUS (in folder: Polaris3_chains) is structured in the following way:

column | type | description
--- |------| ---
`ID` | int  | Id of the message extracted from Reddit
`SENTENCE` | str  | Message from which cause-effect (CE) pair is taken, with target word marked by `<t>` and `</t>` 
`CAUSATION` | str  | Target word evoking the causal relation marked by the CE pair
`Positive/negative` | str  | Polarity of the causal relation
`Aggregated_cause v2.0` | str  | Cause
`Aggregated_effect v2.0` | str  | Effect
`Actor_NRP v1.0` | str  | Actor
`Affected_NRP v1.0` | str  | Affected entity
`custom_id` | str  | Id of the CE pair
`all_causal_chains` | list | All causal chains generated by one LM. Each element is a dictionary containing one chain; {`chain`: list, `chain_length`: int, `causal_relations`: list}, where `chain` contains all intermediate steps (str) of the chain, `chain_length` reflects the length of the chain, and `causal_relations` lists all intermediate CE pairs as {`cause`: str, `effect`: str}.
`num_causal_chains` | int  | Number of causal chains
`causal_chain_0` | str  | String formulation of the first chain 
`causal_chain_1` | str  | String formulation of the second chain (and so on)

The causal chain data for PolarIs4CAUS (in folder: Polaris3_chains) is structured in the following way:

column | type | description
--- |------| ---
`Id_thread` | int  | Id of the X thread from which the message is extracted
`Original_sentence` | str  | Message from which cause-effect (CE) pair is taken
`Modification v1.0` | str  | Grammatical reformulation action performed on the cause and effect
`Cause` | str  | Cause as formulated in the message
`Agent` | str  | Agent as formulated in the message
`Agent_cause` | str  | Cause, or Agent when Cause is NaN
`Cause_NPR v1.0` | str  | Cause after first noun phrase resolution (NPR) reformulation
`Cause_NPR_Refined v1.1` | str  | Cause after second noun phrase resolution (NPR) reformulation
`Primary tag_keyword_cause` | str  | Primary keyword of the overarching topic of the cause
`Secondary tag_keyword_cause` | str  | Secondary keyword of the overarching topic of the cause
`Aggregated_cause v2.0` | str  | Cause
`Positive_or_negative` | str  | Polarity of the causal relation
`Effect` | str  | Effect as formulated in the message
`Effect_NPR v1.0` | str  | Effect after first noun phrase resolution (NPR) reformulation
`Effect_NPR_Refined v1.1` | str  | Effect after second noun phrase resolution (NPR) reformulation
`Primary tag_keyword_effect` | str  | Primary keyword of the overarching topic of the effect
`Secondary tag_keyword_effect` | str  | Secondary keyword of the overarching topic of the effect
`Aggregated_effect v2.0` | str  | Effect
`Causation` | str  | Target word evoking the causal relation marked by the CE pair
`Entity affected` | str  | Affected entity
`Circumstances` | str  | Circumstances
`custom_id` | str  | Id of the CE pair
`all_causal_chains` | list | All causal chains generated by one LM. Each element is a dictionary containing one chain; {`chain`: list, `chain_length`: int, `causal_relations`: list}, where `chain` contains all intermediate steps (str) of the chain, `chain_length` reflects the length of the chain, and `causal_relations` lists all intermediate CE pairs as {`cause`: str, `effect`: str}.
`num_causal_chains` | int  | Number of causal chains
`causal_chain_0` | str  | String formulation of the first chain 
`causal_chain_1` | str  | String formulation of the second chain (and so on)

The two causal chains files build further on PolarIs3CAUS (Pineda and Allein, 2025a) and PolarIs4CAUS (Pineda and Allein, 2025b), which differ in structure and content. Hence, the differences in formatting between the two files. 

### Intermediate Cause-Effect Pairs

CSV files with the intermediate CE pairs extracted from the causal chains generated by each models are included in the folder Intermediate_CE_pairs --> Polaris3_subrelations and Polaris4_subrelations. The file names mention the model that performed the generation, e.g. ```Polaris4_causal_sub-relations_o1.csv``` contains pairs from chains generated by o1.
The causal chain data for PolarIs3CAUS (in folder: Polaris3_chains) is structured in the following way:

column | type | description
--- |------| ---
`custom_id` | str  | Id; e.g., “request-1-5-2”, where the custom_id points to the second CE pair (2) in the fifth causal chain (5) for the original CE pair with custom_id “request-1”
`cause` | str  | Cause
`effect` | str  | Effect


## Code for Reproducing Experiments and Evaluation

Python files containing the code for reproducing the causal chain inference experiments and evaluations A1 - A3 are included in the folder Code; run ```main.py```. The python file for reproducing evaluation A4, Table 3 in the main paper, and the consistency results in A3 is included in the folder LM-Evaluation; run ```main_analysis.py```.

### Requirements

This code requires Python 3.12 or higher.

Before running the code, make sure you have the following dependencies installed:

```bash
pip install -r requirements.txt
```

Prior to running ```main.py```, API keys for OpenAI and NVIDIA NIM need to obtained and included in the code. These can be applied for through their official platforms.

Adjust the implementation and evaluation settings in ```arguments.py``` before running the code. The file includes proper descriptions for each argument. For example, for reproducing the causal chain inference experiment with Deepseek R1, run the following:

```bash
python main.py --generate_chains=True --preprocessing=True --submit_to_deepseek=True
```


## Diagnostic Evaluation Results (A1 - A4)

CSV files with the evaluations of the intermediate CE pairs for evaluations A1-A4 are included in the folder LM-Evaluation, with subfolders for each model that is being evaluated, e.g., deepseek_r1. The file names mention the dataset from which the original CE pairs are taken, the model that is performing the evaluation (e.g., mixtral), and the model that performed the generation (e.g., deepseek r1, e.g. ```Polaris4_all_analyses_mixtral_about_deepseek_r1.csv``` contains pairs from chains generated by o1. 

The files containing self-evaluations, i.e., the model doing the evaluation is the same as the model being evaluated, includes the results for evaluation setups A1 (i.e., ``Does_cause_lead_to_effect``), A2 (i.e., ``Does_effect_lead_to_cause_SWITCH``), A3 (i.e., ``Does_cause_lead_to_effect_PASSIVE`` and ``Does_effect_lead_to_cause_SWITCH_PASSIVE``), and A4 (i.e., combination of A1 and A2).

column | type | description
--- |------| ---
`custom_id` | str  | Id; e.g., “request-1-5-2”, where the custom_id points to the second CE pair (2) in the fifth causal chain (5) for the original CE pair with custom_id “request-1”
`cause` | str  | Cause
`effect` | str  | Effect
`Does_cause_lead_to_effect` | str  | Yes/no answers (A1)
`Does_effect_lead_to_cause_SWITCH` | str  | Yes/no answers (A2)
`Does_cause_lead_to_effect_PASSIVE` | str  | Yes/no answers (A3)
`Does_effect_lead_to_cause_SWITCH_PASSIVE` | str  | Yes/no answers (A3)

The files containing cross-evaluations, i.e., the model doing the evaluation is different from the model being evaluated, includes the results for evaluation setup A4.

column | type | description
--- |------| ---
`custom_id` | str  | Id; e.g., “request-1-5-2”, where the custom_id points to the second CE pair (2) in the fifth causal chain (5) for the original CE pair with custom_id “request-1”
`cause` | str  | Cause
`effect` | str  | Effect
`Does_cause_lead_to_effect` | str  | Yes/no answers (A1)
`Does_effect_lead_to_cause_SWITCH` | str  | Yes/no answers (A2)
